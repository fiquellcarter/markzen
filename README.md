# Markzen

Markzen is an open-source bookmarking tool developed by **Ovela Studio**. It allows you to save, organize, and capture links effortlessly as you browse, with the option to self-host on your infrastructure.

> Markzen is under active development, and new features may be introduced over time.

## Community & Support

- **Issues**: Report bugs, ask questions, or submit feature requests via [GitHub Issues](https://github.com/fiquellcarter/markzen/issues)
